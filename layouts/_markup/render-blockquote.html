The HTML page hides this because --minify collapses it afterwards - the feed is where the hook's real output shows. So the markup is emitted without any whitespace the document does not need, and both output formats get the same clean result. An alert's title is whatever Hugo finds on the first line of its first paragraph. With markup.goldmark.extensions.cjk.eastAsianLineBreaks enabled, every soft line break in that paragraph is dropped before Hugo looks, so the whole paragraph reads as one line and becomes the title: > [!TIP] > This is the body. -> title "This is the body.", no body So the hook reads the marker line back from the source: text after [!TYPE] there is the real title, and anything .AlertTitle holds beyond it is body text and is restored as the first paragraph.
