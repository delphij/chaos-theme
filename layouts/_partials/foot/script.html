{{- /* Emits one script tag: built through js.Build, minified and fingerprinted with an integrity hash in production, unminified with an external source map in development. Every script the theme loads goes through here, so the build options and the tag's attributes cannot drift apart between one script and the next -- which is what happened when the Mermaid glue was written inline in a template and so never saw js.Build at all. target fixes the syntax floor of the output. Without it the emitted syntax is whatever the source happens to be, so the baseline would be decided by accident. es2020 is where the sources already sit -- optional chaining and nullish coalescing are their newest syntax -- so newer syntax can be written freely from here on and esbuild lowers it, rather than silently raising what browsers the theme requires. It cannot express the real floor, which is set by runtime APIs rather than syntax (, IntersectionObserver, CSS.escape, replaceChildren); those are a feature-detection concern, not a build one. @param {string} . The asset path, e.g. "js/main.js". @example: {{ partial "foot/script.html" "js/main.js" }} */ -}} {{- $opts := dict "minify" (not hugo.IsDevelopment) "sourceMap" (cond hugo.IsDevelopment "external" "") "target" "es2020" "targetPath" . -}} {{- with resources.Get . -}} {{- with . | js.Build $opts -}} {{- if hugo.IsDevelopment -}} {{- else -}} {{- with . | fingerprint -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
