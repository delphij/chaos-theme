Called by `typeset-content.html` before CJK whitespace stripping so full-width ideographic spaces (U+3000, used for 挪抬) are preserved. Supports: 1. Standard inline Chaos extensions (emphasis dots, ruby, color swatches) delegated back to `typeset-content.html` with `keepSpace: true`. 2. Hollow circle emphasis (`[文字]{o}`) -> `文字`, matching traditional Chinese commentary circle marks, plus inline size shifts `[文字]{+}` (`.v-large`) and `[文字]{-}` (`.v-small`, subtle right-offset side-script for humble self-references such as 「臣亮」). 3. 抬头 (honorific line elevation): a `

` opening with `^^` becomes `

Both emit hidden `.jiazhu-rp` parentheses so feeds without CSS degrade cleanly to `（注釈）`. @param {string} . Rendered HTML of a single `.vertical` block. @returns {string} Transformed HTML. */ -}} {{- $html := . -}} {{- /* Hollow circle marks and inline size shifts (尊称大字 / 谦称小字). Run before delegating to typeset-content.html so [text]{o}/{+}/{-} are not captured as ruby annotations (o). */ -}} {{- if in $html "]{o}" -}} {{- $html = $html | replaceRE `\[([^\[\]<\n]{1,32})\]\{o\}` `$1` -}} {{- end -}} {{- if in $html "]{+}" -}} {{- $html = $html | replaceRE `\[([^\[\]<\n]{1,32})\]\{\+\}` `$1` -}} {{- end -}} {{- if in $html "]{-}" -}} {{- $html = $html | replaceRE `\[([^\[\]<\n]{1,32})\]\{-\}` `$1` -}} {{- end -}} {{- $html = partial "_funcs/typeset-content.html" (dict "content" $html "keepSpace" true) -}} {{- /* 抬头: leading ^^ (双抬) or ^ (单抬) inside

*/ -}} {{- if findRE `]*>\^` $html -}} {{- $html = $html | replaceRE `

\^\^` `

` -}} {{- $html = $html | replaceRE `(]*\bclass="[^"]*)"([^>]*>)\^\^` `$1 taitou-2"$2` -}} {{- $html = $html | replaceRE `(]*\bclass="[^"]*)"([^>]*>)\^` `$1 taitou-1"$2` -}} {{- end -}} {{- /* 双行夹注 & 行间旁批: - `((:批注))` (or any `((...))` inside `.side-notes`) renders as an interlinear side commentary (`.pangpi`) in the right-hand gutter. - `((注释))` otherwise renders as a balanced two-sub-column warichu note (`.jiazhu`).
