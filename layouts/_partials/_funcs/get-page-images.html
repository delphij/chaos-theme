{{- /* Returns a slice of absolute URLs for page images, with site-level fallbacks. Search order: 1. Front matter "images" param 2. Page bundle image resources matching "feature*", "cover*", "thumbnail*", or first image 3. Site params "defaultImage" or "images" Bundle images are served as a derivative capped at 1200px rather than as the source file, both because social cards do not need more and because it keeps the source unreferenced (see build.publishResources). @context {page} page The page context. @returns {slice} Slice of absolute URL strings. @example: {{ $images := partial "_funcs/get-page-images.html" . }} */}} {{- $images := slice -}} {{- with .Params.images -}} {{- range . -}} {{- $images = $images | append (. | absURL) -}} {{- end -}} {{- end -}} {{- if eq (len $images) 0 -}} {{- with .Resources.ByType "image" -}} {{- $featured := .GetMatch "{*feature*,*cover*,*thumbnail*}" -}} {{- with or $featured (index . 0) -}} {{- $card := . -}} {{- if ne .MediaType.SubType "gif" -}} {{- $width := cond (gt .Width 1200) 1200 .Width -}} {{- $card = .Resize (printf "%dx webp" $width) -}} {{- end -}} {{- $images = $images | append $card.Permalink -}} {{- end -}} {{- end -}} {{- end -}} {{- if eq (len $images) 0 -}} {{- with or site.Params.defaultImage (index site.Params.images 0) -}} {{- $images = $images | append (. | absURL) -}} {{- end -}} {{- end -}} {{- return $images -}}
