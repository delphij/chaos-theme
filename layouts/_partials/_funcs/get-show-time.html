{{- /* Decides whether datetime.html shows the hour and minute (15:04), for the whole site at once: a site shows times on every page or on none, never on some, so a post that happens to be dated at midnight still shows its 00:00. showTime = true always show the time showTime = false never show it showTime = "auto" or unset show it only when the dated pages do not all share one time of day, which is what a site whose front matter gives dates alone looks like Site-wide but language-specific: cache it per language. @example: {{ partialCached "_funcs/get-show-time.html" . site.Language.Lang }} @return {bool} Hugo before 0.166.0 honours only one return per partial, and only at the end: any other return is left in place and fails with "wrong number of args for return". Keep the single return at the bottom while min_version is below that. */ -}} {{- $override := site.Params.showTime -}} {{- $show := false -}} {{- if eq $override true -}} {{- $show = true -}} {{- else if ne $override false -}} {{- $first := "" -}} {{- range site.RegularPages -}} {{- if not .Date.IsZero -}} {{- $t := .Date.Format "15:04" -}} {{- if not $first -}} {{- $first = $t -}} {{- else if ne $t $first -}} {{- $show = true -}} {{- break -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $show -}}
