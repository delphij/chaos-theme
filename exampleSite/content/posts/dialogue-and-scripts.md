人物访谈与戏剧剧本在版式上有相近的视觉诉求：说话人姓名或角色代号需要稳定对齐，与正文发言拉开清晰的纵轴，以便读者快速扫视轮次；同时，在Markdown源码、RSS订阅与纯文本阅读器中，又不宜引入专有短代码而破坏可读性。Chaos基于标准Markdown定义列表与`{.dialogue}`块属性实现这一排版。

<!--more-->

## 语法与设计 {#syntax}

在`hugo.toml`中启用Goldmark块属性解析后，只需在标准定义列表（`术语\n: 解释`）末尾紧接一行`{.dialogue}`即可切换为对话体：

```toml
[markup.goldmark.parser.attribute]
  block = true
```

其排版行为随语境与视口宽度自动调整：

- **宽屏桌面（`>= 960px`）与打印稿**：话者列悬挂于正文左侧栏外，使所有对话正文左缘与前后散文段落对齐。
- **平板与窄屏**：两栏均收束在版心之内；`<= 768px`的手机屏幕转为上下堆叠，话者居上、发言居下。
- **引用块内部**：置于`> `引用块中的对话体保持左缘对齐，不向引用卡片外溢出。
- **连续发言与同时应答**：同一话者连续写多行`: `保持更紧凑的段距；多个话者行连写再接`: `则表示同时发言。

## 人物访谈示例（`{.dialogue}`） {#interview}

访谈体默认使用加粗的标题墨色（`--heading`）突出说话人姓名。下面是一段关于静态站点与文本长久保存的对谈示例：

编者
: 在动态出版平台如此方便的今天，为什么仍有人坚持用Markdown维护静态博客？

作者
: 因为纯文本的寿命远长于某一款软件或服务。十年后，当年的后台数据库或许早已无人维护，但目录里的`index.md`只要能用任意编辑器打开，内容便还在。
: 排版也一样。如果把对白写成专有HTML标签，换个主题或导出成纯文本就会满屏标签；写成Markdown定义列表，即便在最简陋的终端里读起来也依然清楚。

编者
: 那如果访谈里偶尔需要穿插一段简短的旧日摘录呢？

作者
: 直接放进引用块即可，主题会自动把话者收拢到卡片内部：

> 提问者
> : 你们当时决定重写解析器花了多久？
>
> 维护者
> : 一个周末写出原型，随后花了一年处理各种边界情况。
> {.dialogue}

编者
作者
: 简单，但克制。
{.dialogue}

## 剧本与舞台提示（`{.dialogue .script}`） {#script}

排印剧本时，除了将块属性写作`{.dialogue .script}`使话者退居次级墨色（`--muted`），还可直接沿用传统的括注记法，构建期会自动识别并缩小字号、淡化墨色：

- **独立舞台提示**：以`*〔……〕*`独占一段，会被标记为`p.stage`，在`.script`对话块之间保持紧凑的上下节奏（紧接在非`.script`的场景/人物表之后则保留较大间距以区分段落层次）；超过60字的长段开幕布景说明（或显式标注`{.stage-scene}`）会自动标记为`p.stage.stage-scene`，保持正文字号与墨色。
- **行内动作注记**：置于话者名后（如`翁 *（叹气）*`）或插在台词中的`*（……）*`，会被标记为`em.stage`。

下面节选鲁迅先生作于1925年的散文诗剧《过客》（收于《野草》，已进入公有领域）开场一段作为排印示例[^guoke]：

时
: 或一日的黄昏。

地
: 或一处。

人
: 老翁——约七十岁，白须发，黑长袍。
: 女孩——约十岁，紫发，乌眼珠，白地黑方格长衫。
: 过客——约三四十岁，状态困顿倔强，眼光阴沉，黑须，乱发，黑色短衣裤皆破碎，赤足著破鞋，胁下挂一个口袋，支着等身的竹杖。

景
: 东，是几株杂树和瓦砾；西，是荒凉破败的丛葬；其间有一条似路非路的痕迹。一间小土屋向这痕迹开着一扇门；门侧有一段枯树根。
{.dialogue}

*〔女孩正要将坐在树根上的老翁搀起。〕*

翁
: 孩子。喂，孩子！怎么不动了呢？

孩 *（东望着）*
: 有谁走来了，看一看罢。

翁
: 不用看他。扶我进去罢。太阳要下去了。

孩
: 我，——看一看。

翁
: 唉，你这孩子！天天看见天，看见土，看见……

孩 *（回过头来）*
: 老爷爷，他来了。
{.dialogue .script}

*〔过客从东面的杂树间跄踉走出，暂时踌蹰之后，慢慢地走近老翁去。〕*

客
: 老丈，你晚上好？

翁
: 阿，好！托福。你好？

客
: 老丈，我实在冒昧，我想在你那里讨一杯水喝。我走得渴极了。这地方又没有一个池塘，一个水洼。

翁
: 唔，可以可以……。孩子，去取一杯水来。
{.dialogue .script}

*〔女孩向小土屋走去。〕*

翁
: 你大概是远路罢？

客
: 是的，我走得很远了。

翁
: 你是——，贵姓罢？ *（略略迟疑）* 我想借此知道……

客
: 称呼？——我不知道。从我还能记得的时候起，我就只一个人，我不知道我本来叫什么。我一路走，有时人们也随便称呼我，各式各样地，我也记不清楚了，况且相同的称呼也没有听到过第二回。

翁
: 阿阿。那么，你是从哪里来的呢？

客 *（略略迟疑）*
: 我不知道。从我还能记得的时候起，我就这么走。

翁
: 对了。那么，我可以问你到哪里去么？

客
: 这也是我所急于想知道的。……然而我不知道。从我还能记得的时候起，我就在这么走，要走到一个地方去，这地方就在前面。我单记得走了许多路，现在来到这里了。我接着就要走向那边去…… *（指西）*

翁
: 那边？那边是坟。

客 *（稍微惊异）*
: 坟？

孩 *（拿着瓦杯走出来）*
: 不是的。那里有许多野百合，野蔷薇，我都去玩的。

客 *（向女孩看看，又向西看看，仿佛微笑）*
: 不错，我看见过许多野百合和野蔷薇，……那是坟。

翁
: 你到那里去作什么呢？那里没有别的，就是坟。

客
: 但那后面呢？我不知道。也许还有路。……或者终于没有路，只好罢休罢。然而我现在总得走。
{.dialogue .script}

[^guoke]: 节选自鲁迅《野草·过客》（1925年3月2日）。原剧本以「**翁**——」「**孩**——」起行，此处改以Markdown定义列表与`{.dialogue .script}`排印以示范主题效果。
