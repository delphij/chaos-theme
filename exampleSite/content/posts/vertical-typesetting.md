在横排技术文章或读书笔记里引用大段古文、碑刻或传统文献时，
偶尔会希望还原中文「自上而下、由右向左」的直排阅读节奏。
Chaos通过`{.vertical}`块属性将竖排严格限定在独立容器内——
页面主体、导航、目录、代码块、数学公式与RSS订阅继续保持横排，
容器内则以`writing-mode: vertical-rl`排印，
并支持乌丝栏、朱丝栏、抬头、双行夹注、空心圈点与落款。

## 示例：范仲淹《岳阳楼记》 {#yueyanglouji}

下面以北宋范仲淹《岳阳楼记》全文为例，演示乌丝栏（`.ruled`）、朱色行间旁批（`.side-notes`）、每栏约二十二字（`rows=22`）与默认低二格篇名（`title="岳陽樓記"`）的配合；完整Markdown源码如下：

```markdown {.wrap}
> 慶曆四年春((宋仁宗慶曆四年，即公元一〇四四年))，滕子京((滕宗諒，字子京，時貶知岳州))謫守巴陵郡。越明年，政通人和，百廢具興((具，通「俱」，全、皆))[^1]。乃重修岳陽樓，增其舊制，刻唐賢今人詩賦於其上，[屬]{zhǔ}予作文以記之。
>
> 予觀夫巴陵勝狀，在洞庭一湖。銜遠山，吞長江，浩浩[湯湯]{shāng shāng}，橫無際涯；朝暉夕陰，氣象萬千。此則岳陽樓之大觀也，前人之述備矣。然則北通巫峽，南極瀟湘，遷客騷人，多會於此，覽物之情，得無異乎？
>
> 若夫霪雨霏霏，連月不開，陰風怒號，濁浪排空；日星隱曜，山岳潛形；商旅不行，[檣]{qiáng}傾[楫]{jí}摧；薄暮冥冥，虎嘯猿啼。登斯樓也，則有去國懷鄉，憂讒畏譏，滿目蕭然，感極而悲者矣。
>
> 至若春和景明，波瀾不驚，上下天光，一碧萬頃；沙鷗翔集，錦鱗游泳；岸芷汀蘭，郁郁青青。而或長煙一空，皓月千里，浮光躍金，靜影沉璧，漁歌互答，此樂何極！登斯樓也，則有心曠神怡，寵辱偕忘，把酒臨風，其喜洋洋者矣。
>
> 嗟夫！予嘗求古仁人之心，或異二者之為，何哉？[不以物喜，不以己悲]{.}；居廟堂之高則憂其民，處江湖之遠則憂其君。是進亦憂，退亦憂。然則何時而樂耶？其必曰「[先天下之憂而憂，後天下之樂而樂]{o}」乎！噫！微斯人，吾誰與歸？
>
> 時六年九月十五日。
>
> — 宋·[范仲淹](https://zh.wikipedia.org/wiki/%E8%8C%83%E4%BB%B2%E6%B7%B9)
{.vertical .ruled .side-notes rows=22 title="岳陽樓記"}
```

其中：`title="岳陽樓記"`在首叶最右列低二格排印篇名；`.side-notes`将行内的`((...))`转为正文右侧行间的朱色旁批；`[屬]{zhǔ}`转为右侧旁注；`[...]{.}`与`[...]{o}`分别在右侧标出实心着重号与空心圈点；`[^1]`以纵中横正立小字落于右侧留白并自动绑定前字、避免孤悬列首；落款中的维基百科链接按中文竖排规范将虚线下划线置于字左；列数超出当前视口宽度时自动顺次连排、满叶转页，桌面端与移动端均不出现横向滚动条，且每个竖排块右上角均提供「切换为横排阅读」按钮，点击即可退化为同底色、同字号的普通横排引文。全文渲染效果：

## 语法与修饰项 {#syntax}

在开启`[markup.goldmark.parser.attribute] block = true`（主题默认已开启）的前提下，
将引文写作普通Markdown引用块（或独立段落），在块末附加`{.vertical}`即可启用竖排：

| 写法 | 效果 |
| :--- | :--- |
| `{.vertical}` | 素底独立竖排容器 |
| `{.vertical .ruled}` | 乌丝栏（墨色行间界栏） |
| `{.vertical .ruled .red-ruled}` | 朱丝栏（复用米字格朱砂色） |
| `rows=22` / `height="28em"` | 指定每栏字数（如`rows=22`）或直接指定每张纸叶的最大高度（默认`28em`） |
| `cols=10` | 可选，限制每张纸叶的最大列数；超出时自动折成下一张纸叶（未指定时按视口宽度自动分页） |
| `title="岳陽樓記"` | 可选，在首叶最右列排印篇名（不写入侧边栏目录）；默认低二格，附加`.title-flush`可改为顶格 |
| `((注释文字))` | 行内双行夹注（割注），构建期自动均分为右左两行小字；在RSS与无CSS阅读器中自然退化为括号注`（注释文字）` |
| `((:批注文字))` / `{.side-notes}` | 行间旁批（侧注），以朱色小字排在正文右侧行间留白处；单条可用`((:批注))`，整块切换可附加`.side-notes` |
| `[文字]{o}` / `[文字]{.}` | 传统空心圈点与实心着重号，置于竖排字符右侧 |
| `[文字]{+}` / `[文字]{-}` | 行内大字与偏右侧书小字（如奏表中自称「臣」「臣亮」缩小偏右；大字可用于题签或碑刻强调） |
| `[字]{注音}` | 复用主题现有注音语法，在竖排中自动转为右侧旁注 |
| 行内全角空格`　`（U+3000） | 挪抬，竖排容器内保留原样、不作空白压缩 |
| 段首`^` / `^^` | 单抬（高出一字）与双抬（高出二字），容器顶部自动预留天头空间 |
| 末段`— 出处` | 自动排入末栏底部作为落款 |

## 朱丝栏与抬头示例：诸葛亮《前出师表》 {#taitou}

古代公牍、奏表常以抬头示敬：提行提及先皇用**双抬**（`^^`），提行提及当今圣上用**单抬**（`^`），行文中遇尊称则前空一全角格作**挪抬**（`　`），全篇保持字径齐一，仅将臣下自称（「臣亮」「臣」）作小字偏右侧书（`[臣亮]{-}`、`[臣]{-}`）。

下面以蜀汉诸葛亮《前出师表》（简体字）为例，使用`{.vertical .ruled .red-ruled .title-flush rows=24 title="前出师表"}`排印为多叶朱丝栏奏表（篇名演示顶格排法；段首与恳请处作提行抬头，行中频见处以挪抬示敬以兼顾阅读连贯；完整Markdown源码如下）：

```markdown {.wrap}
> [臣亮]{-}言：
>
> ^^先帝创业未半而中道崩殂，今天下三分，益州疲弊，此诚危急存亡之秋也。然侍卫之臣不懈于内，忠志之士忘身于外者，盖追　先帝之殊遇，欲报之于　陛下也。诚宜开张圣听，以光　先帝遗德，恢弘志士之气，不宜妄自菲薄，引喻失义，以塞忠谏之路也。
>
> 宫中府中，俱为一体，陟罚[臧否]{zāng pǐ}((赞扬与批评))，不宜异同。若有作奸犯科及为忠善者，宜付有司论其刑赏，以昭　陛下平明之理，不宜偏私，使内外异法也。
>
> 侍中、侍郎郭攸之、费[祎]{yī}、董允等，此皆良实，志虑忠纯，是以　先帝简拔以[遗]{wèi}　陛下。愚以为宫中之事，事无大小，悉以咨之，然后施行，必能[裨]{bì}补[阙]{quē}漏，有所广益。
>
> 将军向宠，性行淑均，晓畅军事，试用于昔日，　先帝称之曰能，是以众议举宠为督。愚以为营中之事，悉以咨之，必能使[行]{háng}阵和睦，优劣得所。
>
> 亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤臣，此后汉所以倾颓也。　先帝在时，每与[臣]{-}论此事，未尝不叹息痛恨于桓、灵也。侍中、尚书、长史、参军，此悉贞良死节之臣，愿
>
> ^陛下亲之信之，则汉室之隆，可计日而待也。
>
> [臣]{-}本布衣，躬耕于南阳，苟全性命于乱世，不求闻达于诸侯。　先帝不以[臣]{-}卑鄙，猥自枉屈，三顾[臣]{-}于草庐之中，咨[臣]{-}以当世之事，由是感激，遂许　先帝以驱驰。后值倾覆，受任于败军之际，奉命于危难之间，尔来二十有一年矣。
>
> ^^先帝知[臣]{-}谨慎，故临崩寄[臣]{-}以大事也。受命以来，夙夜忧叹，恐托付不效，以伤　先帝之明，故五月渡泸，深入不毛。今南方已定，兵甲已足，当奖率三军，北定中原，庶竭驽钝，攘除奸凶，兴复汉室，还于旧都。此[臣]{-}所以报　先帝而忠　陛下之职分也。至于斟酌损益，进尽忠言，则攸之、祎、允之任也。
>
> 愿
>
> ^陛下托[臣]{-}以讨贼兴复之效[^2]，不效，则治[臣]{-}之罪，以告　先帝之灵。若无兴德之言，则责攸之、祎、允等之慢，以彰其咎；
>
> ^陛下亦宜自谋，以[咨诹]{zī zōu}善道，察纳雅言，深追　先帝遗诏，[臣]{-}不胜受恩感激。
>
> 今当远离，临表涕零，不知所言。
>
> — 蜀汉·[诸葛亮](https://zh.wikipedia.org/wiki/%E8%AF%B8%E8%91%9B%E4%BA%AE)
{.vertical .ruled .red-ruled .title-flush rows=24 title="前出师表"}
```

## 竖排注音符号四声对照 {#bopomofo}

直排容器内同样支持以注音符号（Bopomofo）标音，下例摘录宋·黄庭坚《寄黄几复》与苏轼《饮湖上初晴后雨》名句，集中展示阴平（无调号）、阳平（`ˊ`，如「[湖]{ㄏㄨˊ}」）、上声（`ˇ`）、去声（`ˋ`）以及单符、双符、三符注音在竖排右侧旁注中的显示效果：

> [桃]{ㄊㄠˊ}[李]{ㄌㄧˇ}[春]{ㄔㄨㄣ}[風]{ㄈㄥ}[一]{ㄧ}[杯]{ㄅㄟ}[酒]{ㄐㄧㄡˇ}，[江]{ㄐㄧㄤ}[湖]{ㄏㄨˊ}[夜]{ㄧㄝˋ}[雨]{ㄩˇ}[十]{ㄕˊ}[年]{ㄋㄧㄢˊ}[燈]{ㄉㄥ}。
>
> [水]{ㄕㄨㄟˇ}[光]{ㄍㄨㄤ}[瀲]{ㄌㄧㄢˋ}[灩]{ㄧㄢˋ}[晴]{ㄑㄧㄥˊ}[方]{ㄈㄤ}[好]{ㄏㄠˇ}，[山]{ㄕㄢ}[色]{ㄙㄜˋ}[空]{ㄎㄨㄥ}[濛]{ㄇㄥˊ}[雨]{ㄩˇ}[亦]{ㄧˋ}[奇]{ㄑㄧˊ}。
>
> — 集句（宋·黃庭堅、蘇軾）

> [!NOTE]
> 双行夹注与行间旁批均适用于典籍中简短的词句训诂或眉间短评（单条上限80字符，且不支持嵌套括号）；
> 较长的版本考证或现代白话译注仍建议放在容器外的普通脚注（`[^1]`）或横排正文里，
> 兼顾屏幕可读性与无障碍体验。

[^1]: 本文《岳阳楼记》底本依《范文正公集》卷七正体字排印，保留「具」（通「俱」）、「隱曜」与「郁郁」（馥郁之「郁」，非「鬱」）等古本字形；行间仅以朱色旁批作简短词句训诂，较长的版本与体例说明则借由标准脚注收于文末。
[^2]: 传统奏疏平阙规制中，行文凡遇「先帝」「陛下」等尊称，均在尊称之前断行提抬——因此「愿陛下……」中「愿」字独自收束前一列，「陛下」另起一列单抬；不便处处断行时则在尊称前空一全角格作挪抬（尊称之后不空格，且提行抬头与挪抬互斥）。本示例于段首与「愿陛下」恳请处演示提行抬头，行中频见处以挪抬示敬以兼顾阅读连贯。
