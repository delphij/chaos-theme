低年级语文课本与传统蒙学字帖里常见一种醒目的字词展示版式：
版心正中排开一列淡红米字格，格内端坐大号楷书，格顶标着拼音，
下方再接一段平实的词语释义。Chaos在不引入专有短代码的前提下，
直接复用现有的`[字]{音}`注音语法与`{.mizige}`块属性支持这一版式：
米字格像独立数学公式一样充当居中的视觉锚点，释义留在普通正文段落里，
RSS/Atom订阅与纯文本阅读器也能平稳退化为自然的括号注记。

<!--more-->

## 基本写法与整词自动拆格 {#syntax}

在启用`[markup.goldmark.parser.attribute] block = true`（主题默认已开启）
的前提下，只需将待展示的词条独立成段，并在下一行紧接`{.mizige}`即可。
格顶注音完全沿用主题现有的`[文字]{注音}`或`[文字]^(注音)`语法，
支持两种等价写法：

- **整词连写（自动按空格拆格）**：
  当方括号内的汉字数与花括号内按空白切分的音节数相等时，
  构建期会自动将每个汉字与对应音节一对一拆入各自的米字格，省去逐字敲括号的繁琐。
- **逐字标注**：
  写作`[闪]{shǎn}[身]{shēn}[步]{bù}`（允许在单字单元之间留空格以方便源码阅读），
  渲染结果与整词连写完全一致。

下面借几条近期从二十世纪九十年代高校《中国民间舞教材与教法》
教学录像中意外「破圈」的传统民间舞术语为例，
演示不同字数词条与普通正文释义的配合方式。Markdown源码如下：

```markdown
[闪身步]{shǎn shēn bù}
{.mizige}

源自国家级非物质文化遗产安徽花鼓灯男角「鼓架子」的基本步伐，
讲究重心骤移、急走急停，侧向移步时干净利落，
在短视频二创里常被借来演示「下班打卡或躲避家务时的瞬移身法」。

[浪子踢球]{làng zǐ tī qiú}
{.mizige}

同样出自安徽花鼓灯男班教材。此处的「球」并非现代足球，
而是早期花鼓灯表演中女角「兰花」鞋面所缀的绣球；
男角在与女角逗趣相戏时以单腿轻巧挑踢，身段俏皮舒展而下盘重心沉稳。

[狗熊哆嗦毛]{gǒu xióng duō suo máo}
{.mizige}

源自山东商河鼓子秧歌的基础动律（注意第四字「嗦」标作轻声`suo`）。
表面看去像是随意的晃动，实则讲究「力起于足、沉于膝、蓄于腰、传于肩」，
腰身下沉而双肩作细密沉实的震颤，状如黑熊抖落一身尘毛。顺带一提，
```

## 《千字文》选段与句读混排 {#qianziwen}

排印四言蒙学或八字熟语时，句中的全角逗号、句号、
顿号会自动退入无框的`.mizige-punct`分隔位，不会单独霸占一个米字格；
源码中为满足行宽而在子句间留下的软换行与空格也会被自动忽略：

```markdown
[天地玄黄]{tiān dì xuán huáng}，
[宇宙洪荒]{yǔ zhòu hóng huāng}
{.mizige}
```

渲染效果（节选梁代周兴嗣《千字文》开篇）：

[天地玄黄]{tiān dì xuán huáng}，
[宇宙洪荒]{yǔ zhòu hóng huāng}
{.mizige}

「玄黄」语出《周易·坤卦·文言》「夫玄黄者，天地之杂也，天玄而地黄」，
指天色深青苍莽、地色广袤浑黄；「洪荒」则形容草昧初开、
混沌蒙昧的远古太初。在桌面端`780px`版心与A4打印稿中，
八字加一枚逗号恰好一行居中排开；当窗口收窄不足以容纳整行八字时，
子句分组优先在逗号之后断开为上下对称的两行四字格（避免拆成前六后二），
同时行末逗号向外侧零宽悬挂，使上下两行的四列方格严格对齐。

## 局部训诂、跨格义训与纯字帖 {#gloss}

除了给整条成语逐字标拼音，
`{.mizige}`还覆盖了古文训诂与书法字帖中常见的三种变体。

### 按需局部加注

熟字直接裸写，只对生僻字、多音字或需要训释的单字加`[字]{注}`。
未加注的单字同样各自进入米字格，
外框底边与字面中宫严格对齐（下例仍取自《千字文》，仅对单字训诂与多音字标音）：

```markdown
日月[盈]{满}[昃]{zè}，辰[宿]{xiù}列张
{.mizige}
```

日月[盈]{满}[昃]{zè}，辰[宿]{xiù}列张
{.mizige}

### 跨格连绵义训

当方括号内的汉字数与花括号内的分段数不等时（例如给双声、
叠韵连绵词整体加注），底层依然维持每字一格，
而上方的`<rt>`注文自动横跨相邻字格居中对齐（下例前四字取自《千字文》
「束带矜庄，徘徊瞻眺」）：

```markdown
[徘徊]{叠韵}瞻眺，[犹豫]{双声}不决
{.mizige}
```

[徘徊]{叠韵}瞻眺，[犹豫]{双声}不决
{.mizige}

### 无注文纯字帖

完全不写`{...}`注记时，上方不预留空白行高，直接排作纯粹的楷书米字格字帖：

```markdown
天下为公
{.mizige}
```

天下为公
{.mizige}

## 版式比例与降级细节 {#design}

- **大字原比例楷体与中宫校准**：
  正文小字号强调所使用的`--font-em`会对楷体做字重提升与`106%`字面放大以
  匹配黑体灰度；米字格展示字号较大（桌面端外框`72px`、窄屏`60px`、
  打印稿`41pt`约合实物生字本`14.5mm`方格），
  因此改用常规字重原比例楷体栈`--font-mizige`，按传统字帖「中宫收紧、
  四周留白」的惯例取格宽的`74%`，并针对华文楷体、霞鹜文楷、
  中易楷体与标楷体各自不同的字面基线逐一校准，
  使汉字重心落在米字虚线的中心交点上。
- **注文对位与选区净化**：`<rt>`固定为正体无衬线字体，
  在外框顶边上方留出容纳`g`、`p`、`q`、
  `y`下延笔画与`ǚ`叠音符的呼吸间隙，
  并设为不可选中（`user-select: none`），
  鼠标拖选词条时剪贴板只会复制干净的汉字本身。
- **无样式订阅与检索兼容**：双层格线由主题和色`--primary`（浅色蘇芳、
  深色退紅）派生；
  在不加载CSS的RSS/Atom阅读器中退化为`闪（shǎn）身（shēn）步（bù）`普通段落，
  离线全文检索索引也会同时收录汉字词条与拼音注文。
- **格内只容纳字、注音与脚注**：米字格段落按字拆格、按句读分组，
  行内格式无法跨越格子与子句边界而保持合法的HTML嵌套，
  因此格内的强调、链接、行内代码等标记只保留文字、丢弃标签，
  `[字]{.}`着重号也只保留文字；需要强调或链接时，请写在下方的释义段落里。
  脚注引用`[^1]`与注音不受影响。
  行末硬换行（行尾两个空格或反斜杠）与全角空格一样视作子句分隔，
  版心够宽时两侧子句仍排在同一行，收窄时优先在此处折行。
